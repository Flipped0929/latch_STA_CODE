# S27 理论交叉验证 ver.4

ver.4 继续 ver.3 的延迟敏感性方向，但增加了一个关键步骤：当 `Dmax/Dmin` 发生变化时，不只检查原来的时序方案是否失败，还重新求解 `T/W/skew`。这样可以区分两件事：原方案是否对延迟变化鲁棒，以及延迟变化后能否通过重新设计时序参数恢复可行。

## ver.3 到 ver.4 的改进

| 项目 | ver.3 | ver.4 |
| --- | --- | --- |
| 延迟变化后的处理 | 固定 ver.2 的 `T/W/skew`，直接检查 | 对每个合法扰动重新优化 `T/W/skew` |
| 研究问题 | 原方案能否承受延迟变化 | 延迟变化后理论上还能否重新找到可行方案 |
| 记录内容 | 固定方案静态/行为结果 | 固定方案与重新优化方案的周期、窗口、skew、裕量、关键边和行为结果对比 |
| 结论边界 | 固定方案的鲁棒性 | 理论模型内的重新调度能力，不代表硬件可以在线自适应 |

## 实验设置

使用 ver.2 的 10 条 S27 聚合延迟边和 `0.10 ns` 统一 hold 要求。`Dmax` 和 `Dmin` 分别乘以 `-10%、-5%、0、+5%、+10%` 对应的缩放因子，共 25 个组合。若某条边出现 `Dmin>Dmax`，该组合不是合法延迟区间，单独写入 `invalid_perturbations.csv`，不参与重新优化。

对每个合法组合：

1. 用 ver.2 的差分约束和简单环枚举方法重新求最小周期 `T`，再在该周期下最大化透明窗 `W`。
2. 用重新求出的 skew 重算 10 条边的 setup、extended setup、hold 裕量。
3. 将固定 ver.2 方案和重新优化方案都送入 ver.1 的 XOR 事件模型，用 ver.3 中的 14 个代表性确定性模式做功能对照。
4. 用同一组扰动后的最小延迟和 seed `2701` 做动态 hold 补充诊断；静态全边检查仍是主要判定。

## 结果

| 指标 | 结果 |
| --- | ---: |
| 扰动组合总数 | 25 |
| 合法扰动组合 | 15 |
| 非法 `Dmin>Dmax` 组合 | 10 |
| 固定方案静态通过 | 1 / 15 |
| 重新优化后静态通过 | 15 / 15 |
| 固定方案行为通过样本总数 | 93 / 210 |
| 重新优化后行为通过样本总数 | 210 / 210 |
| 固定方案动态 hold 通过 | 11 / 15 |
| 重新优化后动态 hold 通过 | 15 / 15 |

代表性的 nominal 点仍为 `T=5.06070 ns`、`W=0.39099 ns`。在 `Dmax`、`Dmin` 同时降低 10% 的合法扰动下，重新优化得到约 `T=4.55463 ns`、`W=0.34189 ns`；在两者同时提高 10% 时，重新优化得到约 `T=5.56677 ns`、`W=0.44009 ns`。这说明在当前理论模型中，延迟变差主要表现为可实现周期上升，重新调整 skew 和透明窗仍可恢复静态可行性。

## 文件

- `retune_s27_v4.py`：主脚本，执行合法扰动筛选、固定方案检查、重新优化和行为复核。
- `results/retuned_sensitivity.csv`：15 个合法扰动的逐点对比，包括固定/重新优化的 `T/W/skew`、静态裕量、动态 hold、行为通过数、限制边和完整活动约束环。
- `results/invalid_perturbations.csv`：10 个 `Dmin>Dmax` 的非法扰动组合及具体边。
- `results/summary.json`：总计数、nominal 参数、数据散列和汇总结果。
- `tests/test_retune_s27_v4.py`：标准库单元测试。
- `make_figures.py`：只用 Python 标准库生成重新优化趋势图。
- `figures/retuned_sensitivity.svg`：重新优化周期和透明窗变化图。
- `figures/retuned_vs_fixed.svg`：固定方案与重新优化方案的 `T/W` 对比图。

## 复现

在 ver.4 目录运行：

```powershell
python retune_s27_v4.py
python -m unittest discover -s tests -v
python make_figures.py
```

## 局限性

本版仍使用 ver.1 的 XOR 时序图行为模型和 ver.2 的聚合 `Dmax/Dmin`。它不包含真实门级逻辑、器件库、时钟抖动、亚稳态、布局布线寄生或 FPGA 在线调参。所谓“重新优化”是离线理论分析：它回答“如果设计者知道延迟变化并重新选择时序参数，模型是否仍有解”，不表示实际电路会自动适应延迟。

此外，行为复核只覆盖 14 个代表模式和有限周期；动态 hold 只统计被激励出的跳变。最终结论应以重新优化后的静态逐边约束为主，行为结果作为独立交叉证据。
